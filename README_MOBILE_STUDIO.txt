PBS Map Studio Android wrapper - 0.26.13

Use this ZIP by importing the PROJECT ROOT into a Gradle-capable Android build service. Do not upload the enclosing folder as an extra nested directory.

Project files include Gradle settings, Android app source, WebView wrapper, editor HTML, a placeholder icon asset, and GitHub Actions workflow.

The build is not validated here because an Android SDK/build environment is unavailable. WebView 3D/WebGL and model import/export should be tested on-device after APK creation.

For GitHub Actions: push project root contents to a repository, then Actions > Build PBS Map Studio APK > Run workflow; download the APK artifact only if the workflow succeeds.
